# 세금신고 — 강사 지급·원천세 관리 웹앱

강사·교직원 지급 내역과 원천세를 **연도별 · 1월~12월**로 관리하는 브라우저 앱(PWA)입니다.
엑셀(`.xlsx`) 파일을 그대로 불러와 표로 보여 주고, 고친 내용을 다시 엑셀로 저장합니다.

- 주소: `https://hong3256.github.io/tax-manager/`
- 이 저장소에는 **실제 이름·급여·시트 주소가 하나도 들어 있지 않습니다.** 빈 도구만 있습니다.

## 무엇을 하나요

| 기능 | 설명 |
| --- | --- |
| 연도 탭 | 상단에 `2026년` `2027년` `2028년` 탭(`＋ 연도`로 추가). 연도마다 1월~12월 자료가 **따로** 저장되고, 2027·2028년은 근로소득 요약 기본 줄(`17일·25일·말일`)이 미리 들어 있습니다. 연도마다 다른 구글 시트를 연결할 수 있습니다. |
| 📥 엑셀 불러오기 | `지급일자·이름·건명·지급액` 머리글이 있는 시트를 월 이름(`1월`~`12월`)으로 찾아 읽습니다. 금액·세율·신고율 서식(`ROUNDDOWN((D*3%),-1)` 등)도 함께 읽어 옵니다. 파일 이름(또는 `누적합계` 시트 제목)의 연도 탭으로 들어가고, `누적합계` 시트는 건너뜁니다. |
| 💾 엑셀(.xlsx) 저장 | 화면의 1월~12월을 **수식이 살아 있는** `.xlsx`로 내려받고, 맨 끝에 `누적합계` 시트(월별 누적 + `=SUM` 연간 누적합계 + 강사별 누적)를 함께 넣습니다. 파일 이름은 `{연도}년_세금신고_수정본.xlsx`. |
| 요약표 | 근로/일용/퇴직 줄을 더하고 빼며 소계·총계를 자동 계산합니다. |
| 지급 내역표 | 행 추가(＋)·삭제(－)·이름/건명 검색, **🔄 건명 바꾸기**(건명 속 같은 글자·숫자를 현재 월만 또는 올해 1월~12월 전체에서 한꺼번에 치환, 바꾸기 전 건수·예시 미리보기, 실행취소), 소득세(**3%·10원 절사**)·주민세(**10%·10원 절사**)·합계 자동 계산, 방과후강사 신고금액(14.9% / 19.3% / 지급액−세액 / 미적용) 토글. |
| 누적합계 | 12개월 탭 맨 끝. 선택한 연도의 연간 누적 총계 카드(건수·지급액·소득세·주민세·세액·신고금액·근로 급여·근로 세액), 월별 누적 표(마지막 `연간 누적합계` 행), 강사별 연간 누적 표(검색·정렬), 연도별 전체 누적 비교. |
| 🖨️ 인쇄·PDF | 인쇄할 때 버튼·탭은 숨고 표만 A4 가로로 나옵니다. |
| 🔗 구글 시트 연동(선택) | Apps Script 주소와 비밀번호를 넣으면 그 연도의 시트 1월~12월 탭과 주고받을 수 있습니다(연도별로 따로 설정). |

입력한 내용은 **그 브라우저(localStorage)에만** 저장되고 서버로 보내지 않습니다.

## 쓰는 법

1. 상단 연도 탭에서 연도를 고릅니다(`2026년`·`2027년`·`2028년`).
2. `📥 엑셀 불러오기`로 기존 `2026년 세금신고.xlsx`를 고릅니다(파일 이름의 연도 탭으로 들어갑니다).
3. 표에서 금액·이름·건명을 고치면 소득세·주민세·합계가 바로 다시 계산됩니다.
   - 건명의 `11월`을 `12월`로 바꾸는 것처럼 같은 글자를 한꺼번에 바꿀 때는 지급 내역표 위 **🔄 건명 바꾸기** → 찾을 글자·바꿀 글자를 넣고, 범위(현재 월만 / 올해 전체)를 고른 뒤 **적용**. 바뀔 건수와 예시가 먼저 보이고, 적용 후 토스트의 **실행취소**로 한 번에 되돌릴 수 있습니다.
4. `💾 엑셀(.xlsx) 저장` → `2026년_세금신고_수정본.xlsx`(1월~12월 + `누적합계` 시트)가 내려받아집니다.
5. 폰에서도 열립니다. 표는 옆으로 밀어서 봅니다. 홈 화면에 추가하면 앱처럼 뜹니다.

### 계산 규칙

- 소득세 = `ROUNDDOWN(지급액 × 3%, -1)` — 10원 미만 절사 (행마다 8%, 면세, 직접 입력으로 바꿀 수 있음)
- 주민세 = `ROUNDDOWN(소득세 × 10%, -1)`
- 합계 = 소득세 + 주민세
- 방과후강사 신고금액 = `지급액 − (지급액 × 14.9%)` (학기·연도에 따라 19.3%, `지급액 − 세액`, 미적용 중 선택)
- 새로 추가한 지급 줄은 소득세율 `3%`로 시작합니다(8%·면세·직접 입력으로 바꿀 수 있음)

### 연도를 넘길 때

- `＋ 연도`로 다음 연도 탭을 만들면 1월~12월 기본 틀이 생깁니다.
- 새 연도가 비어 있으면 `전년도 틀 가져오기` 단추로 전년도의 **강사명·건명만** 빈 금액으로 복사해 금액만 채울 수 있습니다.
- 예전 판(2026년 한 해만 있던 저장 자료)은 그대로 **2026년 탭**으로 이어받습니다.

## 구글 시트와 연결하려면 (선택)

1. 구글 시트를 열고 **확장 프로그램 → Apps Script**.
2. `tax-apps-script.txt`(이 저장소에는 없습니다 — 별도로 받은 파일) 내용을 전체 붙여넣고 저장.
3. **배포 → 새 배포 → 웹 앱**: 실행 계정 `나`, 액세스 권한 `모든 사용자` → 배포 → 나오는 `…/exec` 주소 복사.
4. 앱의 `🔗 시트 연결`에 주소와 비밀번호(스크립트의 `TOKEN`, 기본 `0629`)를 넣고 `연결 확인`.
5. `⬇ 시트에서 불러오기` / `⬆ 시트로 저장`.

주소와 비밀번호는 **그 기기 브라우저에만** 저장되고, 엑셀 파일에는 들어가지 않습니다.

## 알아 둘 점

- `.xlsx` 저장은 **수식·열 너비·천 단위 서식·병합**을 살립니다. 셀 배경색·굵게 같은 꾸밈은
  브라우저용 SheetJS(무료 판)가 파일에 쓰지 못해 빠집니다.
- 아주 큰 표(수천 행)는 브라우저 메모리를 많이 씁니다. 시트 연동은 한 월 3,000행까지로 막아 두었습니다.
- 이 앱은 개인 기록 관리 도구입니다. 세무 신고 전에는 담당 회계·세무 담당자 확인을 권합니다.
